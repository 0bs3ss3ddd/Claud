# Формат учебного контента ПАРТЫ

Каждый предмет — ES-модуль `content/subjects/<id>.js` с `export default { ... }`.
Сервер загружает все модули, проверяет их (`npm run check:content`) и отдаёт клиенту
**публичную** версию: поля `hints` и `full` у задач вырезаются и выдаются только
через наставника (тариф «Отличник» или бесплатный разбор недели).

## Схема предмета

```js
export default {
  id: 'phys',                     // латиница, совпадает с именем файла
  name: 'Физика',                 // как в меню
  display: 'ФИЗИКА',              // для огромного заголовка (капсом)
  color: 'violet',                // blue | mint | lavender | ember | sun | violet
  sticker: 'atom',                // см. public/js/stickers.js
  tagline: 'Одна строка о предмете',
  sdamgia: 'https://phys-ege.sdamgia.ru',   // поддомен «Решу ЕГЭ»
  exam: {
    tasks: 26,                    // число заданий КИМ
    duration: '3 ч 55 мин',
    minScore: 36,                 // минимальный тестовый балл
    maxPrimary: 45,               // максимум первичных (можно null)
    note: 'Короткая заметка о формате (markdown)',
  },
  // ЛИБО нумерованный список линий КИМ...
  structure: [{ n: '1', topic: 'Кинематика', part: 1, points: 1 }],
  // ...ЛИБО разделы, если нумерация нестабильна:
  sections: [{ title: 'Механика', items: ['Кинематика', 'Динамика'] }],
  theory: [{ title: 'Заголовок карточки', body: String.raw`markdown` }],
  tasks: [ /* задачи ЕГЭ и олимпиадные, см. ниже */ ],
  olymp: {
    intro: String.raw`markdown`,
    vsosh: String.raw`markdown про ВсОШ по предмету`,
    rsosh: [{ name: 'Олимпиада «Физтех»', org: 'МФТИ', note: 'коротко' }],
    topics: ['Тема 1', 'Тема 2'],
    links: [{ title: 'MathUs — физика', url: 'https://mathus.ru/phys/', note: 'что там' }],
  },
};
```

## Задача

```js
{
  id: 'e4',                 // уникален в предмете; e* — ЕГЭ, o* — олимпиада
  kind: 'ege',              // 'ege' | 'olymp'
  n: '4',                   // номер линии КИМ (для ЕГЭ) или null
  title: 'Классическая вероятность',
  level: 'база',            // ЕГЭ: база | повышенный | высокий; олимпиада: школьный этап | региональный | перечневая
  statement: String.raw`условие (markdown)`,
  answer: '0,72',           // краткий ответ; null, если ответ развёрнутый
  accept: ['18/25'],        // необязательно: другие формы верного ответа
  short: String.raw`краткое решение — БЕСПЛАТНО`,
  hints: [String.raw`подсказка 1`, String.raw`подсказка 2`],  // ПЛАТНО
  full: String.raw`разбор со всеми объяснениями — ПЛАТНО`,
}
```

## Markdown

Поддерживается безопасное подмножество: `#`/`##`/`###`, абзацы, `**жирный**`,
`*курсив*`, `` `код` ``, списки `-` и `1.`, цитаты `>`, таблицы `| a | b |`,
ссылки `[текст](https://...)`, формулы `$...$` и `$$...$$` (KaTeX).
Любой HTML экранируется.

Внутри `String.raw` нельзя использовать обратные кавычки и `${`, поэтому
код оформляется директивой `:::code python`, а визуальные блоки — директивами:

```
:::graph
{"title": "y = x^2", "x": [-3, 3], "y": [-1, 9],
 "functions": [{"f": "x^2", "label": "y = x²", "color": "blue"}],
 "points": [{"x": 0, "y": 0, "label": "O"}],
 "segments": [{"from": [0, 0], "to": [2, 4], "dashed": true}],
 "polygons": [{"points": [[0,0],[2,0],[2,4]], "fill": "lavender"}],
 "circles": [{"center": [0, 0], "r": 1}],
 "vlines": [1], "hlines": [4]}
:::

:::chart
{"title": "Население, млн", "labels": ["2000", "2010"], "values": [146.9, 142.9], "unit": "млн"}
:::

:::map
{"title": "Куликовская битва, 1380", "center": [54.0, 38.6], "zoom": 6,
 "markers": [{"lat": 53.65, "lng": 38.66, "label": "Куликово поле", "note": "8 сентября 1380"}],
 "paths": [{"points": [[55.75, 37.62], [53.65, 38.66]], "label": "Путь войска Дмитрия"}]}
:::

:::image
{"wiki": "Утро стрелецкой казни", "caption": "В. И. Суриков, 1881"}
:::

:::code python
print(sum(range(10)))
:::
```

* Цвета: `blue`, `mint`, `lavender`, `ember`, `sun`, `violet`, `black`.
* Функции в `graph`: переменная `x`, операции `+ - * / ^`, скобки, `sin cos tan
  sqrt abs ln log exp`, константы `pi`, `e`. Умножение пишется явно: `2*x`.
* `image.wiki` — точное название статьи русской Википедии: картинка берётся
  из её заглавной иллюстрации (картины, карты, портреты).
