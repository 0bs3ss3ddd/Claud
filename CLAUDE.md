# Правила проекта

## Дизайн-задачи — строго по UI/UX Pro Max

Любая задача, связанная с дизайном, выполняется **строго по скиллу `ui-ux-pro-max`**
(установлен в `.claude/skills/ui-ux-pro-max/`, источник:
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).

К дизайн-задачам относятся: презентации и слайды, лендинги и веб-страницы, UI
приложений и компонентов, дашборды, графики, баннеры и обложки, логотипы,
иконки, фирменный стиль, дизайн-системы и токены, картинки для соцсетей, а также
ревью или переделка существующего дизайна.

Порядок работы:

1. Сначала вызвать скилл `ui-ux-pro-max` через Skill и следовать его Workflow.
2. Для новой страницы, презентации или проекта обязательно сгенерировать
   дизайн-систему:
   `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<тип продукта> <отрасль> <ключевые слова>" --design-system -p "<Название>"`,
   затем уточнить детали поиском по нужным `--domain` и `--stack`.
3. Подключить профильный под-скилл из того же пакета:
   - презентации, питч-деки, слайды → `slides` (и `design-system` для поиска
     по базе слайдов: `.claude/skills/design-system/scripts/search-slides.py`);
   - логотипы, CIP, иконки, картинки для соцсетей → `design`;
   - баннеры и обложки → `banner-design`;
   - фирменный стиль, tone of voice → `brand`;
   - токены и спецификации компонентов → `design-system`;
   - shadcn/ui, Tailwind → `ui-styling`.
4. Перед сдачей пройти правила приоритетов скилла (доступность, контраст 4.5:1,
   адаптивность, типографика, анимация) и чек-лист из
   `.claude/skills/ui-ux-pro-max/references/pro-rules.md`.

Если рекомендации `ui-ux-pro-max` расходятся с другими дизайн-скиллами в этом
репозитории (`design-taste-frontend`, `high-end-visual-design`, `minimalist-ui`,
`impeccable` и т. п.), приоритет у `ui-ux-pro-max`. Обязательные шаги платформы
(например, quickstart и требования к Artifact-страницам) по-прежнему
выполняются, но стиль, палитра, шрифты, макет и UX-решения берутся из
`ui-ux-pro-max`.
