# ПАРТА — онлайн-репетитор для ЕГЭ и олимпиад

Сайт для подготовки к ЕГЭ по 12 предметам и к олимпиадам (ВсОШ и перечневые олимпиады РСОШ) со встроенным ИИ-наставником. Дизайн — по `DESIGN.md` «Slush»: пастельные фоны, огромные «надувные» заголовки, 3D-лента, стикеры с чёрным контуром, pill-кнопки, без теней и градиентов.

## Что умеет

| | «Ученик» — 0 ₽ | «Отличник» — 499 ₽ / 30 дней |
|---|---|---|
| Структура экзамена, шпаргалки, ссылки на каталог «Решу ЕГЭ» | ✓ | ✓ |
| Задачи с проверкой ответа и кратким решением | ✓ | ✓ |
| Олимпиадный раздел (ВсОШ, РСОШ, темы, задачи, MathUs) у каждого предмета | ✓ | ✓ |
| Наставник: подсказки по шагам, полное решение со всеми объяснениями, вопросы | 1 задача в неделю (до 6 сообщений) | без недельного лимита (40 сообщений/сутки, настраивается) |
| **Решатель ЕГЭ** — вставь любую задачу, получи разбор | пробно, в рамках разбора недели | ✓ |
| Графики и чертежи, диаграммы, карты (Leaflet + OpenStreetMap), картины и портреты (Википедия) в объяснениях | в разборе недели | ✓ |

* Бесплатный разбор недели обновляется каждый понедельник в 00:00 по Москве и привязан к одной задаче или одному диалогу Решателя.
* «Отличник» — разовый платёж без автосписаний. Повторная оплата добавляет 30 дней к текущему сроку.

### Предметы
Математика (профиль и база), русский язык, физика, информатика, химия, биология, история, обществознание, география, литература, английский язык. У каждого предмета:
- **ЕГЭ**: параметры экзамена, линии КИМ или тематические разделы со ссылками на каталог [«Решу ЕГЭ»](https://ege.sdamgia.ru/prob_catalog), шпаргалки, 5–7 задач с разбором;
- **Олимпиады**: ВсОШ по предмету, список олимпиад РСОШ, темы, 2–3 олимпиадные задачи с разбором, материалы ([MathUs](https://mathus.ru/) для математики и физики, архивы ВсОШ, [rsr-olymp.ru](https://rsr-olymp.ru/)).

> Задания «Решу ЕГЭ» и материалы MathUs на сайт **не копируются**. ПАРТА ссылается на каталоги этих сайтов по каждому предмету и номеру задания. Собственные задачи-образцы с решениями лежат в `content/subjects/*.js`. Авторские материалы сторонних сайтов импортируйте только с разрешения правообладателей.

## Как устроен наставник

- **Подсказки и полные решения задач каталога** — заранее написанные и проверенные тексты. Они отдаются мгновенно и бесплатно для сервера, но только после проверки доступа. В публичном API полей `hints` и `full` нет.
- **Вопросы по задаче и Решатель** работают через ИИ. Подключается любой из четырёх провайдеров или сразу несколько: **GigaChat** (Сбер), **YandexGPT** (Яндекс), **DeepSeek**, **Claude** (Anthropic). Ответ идёт потоком через SSE. В контекст передаётся эталонное решение задачи, поэтому наставник не расходится с правильным ответом.
- **Резерв.** `TUTOR_PROVIDERS=gigachat,yandexgpt,deepseek` — если первый провайдер не ответил (сбой, перегрузка, неверный ключ), запрос сразу уходит следующему. Ученик видит, какой ИИ ответил: «Наставник · GigaChat».
- Наставник рисует сам: в ответе он может вставить блоки `:::graph`, `:::chart`, `:::map`, `:::image`, и фронтенд превращает их в SVG-график, диаграмму, карту Leaflet или картину из Википедии. Формат описан в [`content/README.md`](content/README.md).
- Без ключей ИИ сайт работает в демо-режиме: каталог задач доступен, свободный диалог честно сообщает, что ИИ не подключён, и пробную попытку не тратит.

## Запуск

Нужен Node.js ≥ 22.13: используется встроенный `node:sqlite`, внешних баз нет.

```bash
npm install
cp .env.example .env      # и заполните ключи
npm start                 # http://localhost:3000
npm test                  # автотесты: доступ, оплата, CSRF, XSS, ИИ-провайдеры на мок-серверах
npm run check:content     # проверка учебного контента, формул и визуальных блоков
```

Локально без ключей всё работает сразу: наставник в демо-режиме, оплата тестовая (кнопка «Оплатить (тест)» без денег).

### Переменные окружения
Все переменные с комментариями — в [`.env.example`](.env.example). Главные:

| Переменная | Зачем |
|---|---|
| `PUBLIC_URL` | публичный адрес (https). От него зависят ссылки возврата из ЮKassa, проверка Origin и флаг `Secure` у cookie |
| `TUTOR_PROVIDERS` | порядок ИИ-провайдеров: основной и резервные |
| `GIGACHAT_AUTH_KEY`, `GIGACHAT_CA_CERT` | GigaChat |
| `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | YandexGPT |
| `DEEPSEEK_API_KEY` | DeepSeek |
| `ANTHROPIC_API_KEY` | Claude |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | боевые платежи |
| `PAYMENTS_DEMO` | тестовая оплата; в `production` по умолчанию выключена |
| `TRUST_PROXY` | число прокси перед приложением, чтобы лимиты считали реальный IP |

### Подключение ИИ-провайдеров

**GigaChat (Сбер)** — работает из России, оплата российской картой, для физлиц есть бесплатный пакет токенов (Freemium).
1. Зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru/studio), создайте проект GigaChat API.
2. Скопируйте **ключ авторизации** в `GIGACHAT_AUTH_KEY`. Для физлица scope `GIGACHAT_API_PERS`, для ИП/юрлица — `GIGACHAT_API_B2B` или `GIGACHAT_API_CORP`.
3. Скачайте корневой сертификат НУЦ Минцифры (`russian_trusted_root_ca.cer`) с [gosuslugi.ru/crt](https://www.gosuslugi.ru/crt), положите в `certs/` и укажите путь в `GIGACHAT_CA_CERT`. Без него Node не доверяет серверам Сбера. Если при запуске появится предупреждение, что эта версия Node не умеет добавлять сертификаты из кода, задайте вместо этого системную переменную `NODE_EXTRA_CA_CERTS=/путь/к/сертификату`.

**YandexGPT (Яндекс)** — работает из России, оплата через Yandex Cloud.
1. В [консоли Yandex Cloud](https://console.yandex.cloud/) создайте каталог, в нём — сервисный аккаунт с ролью `ai.languageModels.user`.
2. Создайте для аккаунта **API-ключ** → `YANDEX_API_KEY`. ID каталога → `YANDEX_FOLDER_ID`.
3. Модель по умолчанию — `yandexgpt/latest` (YandexGPT Pro). Дешевле — `yandexgpt-lite/latest`.

**DeepSeek** — дешёвый и сильный в математике. Ключ получите на [platform.deepseek.com](https://platform.deepseek.com/) → `DEEPSEEK_API_KEY`. Модель по умолчанию — `deepseek-v4-pro` с режимом рассуждений. Дешевле — `deepseek-flash`. Серверы находятся в Китае: это трансграничная передача данных, она отражена в политике конфиденциальности.

**Claude (Anthropic)** — ключ на [console.anthropic.com](https://console.anthropic.com/) → `ANTHROPIC_API_KEY`. Anthropic официально не работает с Россией.

Политика конфиденциальности на сайте сама перечисляет подключённых провайдеров и страны, куда уходят вопросы учеников.

### Подключение ЮKassa
1. Создайте магазин в ЮKassa и возьмите `shopId` и секретный ключ (Интеграция → Ключи API).
2. В разделе «HTTP-уведомления» укажите `https://<ваш-домен>/api/webhooks/yookassa` и события `payment.succeeded` и `payment.canceled`.
3. Если магазин подключён к онлайн-кассе (54-ФЗ), включите `YOOKASSA_SEND_RECEIPT=true`: чек уйдёт на email ученика.
4. Заполните реквизиты в шаблонах **оферты** (`/terms`) и **политики конфиденциальности** (`/privacy`) — файл `public/js/views/legal.js`. ЮKassa проверяет эти страницы при подключении.

Уведомлению ЮKassa сервер не верит на слово: по `id` из уведомления он запрашивает платёж через API и включает тариф, только если платёж `succeeded`, сумма 499.00 RUB и `metadata.payment_id` совпадает с заказом. Повторные уведомления тариф не продлевают.

### Продакшен
- Запускайте за HTTPS-прокси (nginx, Caddy, облачный балансировщик), `NODE_ENV=production`, `TRUST_PROXY=1`.
- Регулярно делайте резервную копию файла базы `DB_PATH` (SQLite в режиме WAL).
- Стоимость ИИ зависит от провайдера и модели. При тарифе 499 ₽ в месяц следите за расходами в кабинете провайдера. Если нужно, выберите модель дешевле или снизьте `PRO_DAILY_MESSAGES`.

## Структура

```
server/            Express 5: auth, тарифы и пробная неделя, наставник, ЮKassa, картинки, заголовки безопасности
server/llm/        ИИ-провайдеры: GigaChat, YandexGPT, DeepSeek, Claude + резервирование
public/            SPA без сборки: index.html, css/, js/ (роутер, страницы, рендер markdown+KaTeX, графики, карты)
content/subjects/  учебный контент по предметам (ЕГЭ + олимпиады); формат — content/README.md
scripts/           check-content.mjs — валидатор контента
test/              node:test — API, оплата, модульные тесты
SECURITY.md        отчёт о проверке безопасности
```

## Безопасность
Подробный отчёт — в [SECURITY.md](SECURITY.md). Коротко:
- пароли хранятся как scrypt-хэш, сессия лежит в HttpOnly SameSite cookie, в базе — только SHA-256 токена;
- от CSRF защищают обязательный заголовок и проверка Origin, выставлены CSP без inline-скриптов, HSTS и запрет фреймов;
- markdown экранируется до разметки, парсер формул для графиков работает без `eval`;
- платный контент не попадает в публичный API, платёж сверяется через API ЮKassa, лимиты попыток и сообщений списываются атомарно;
- действуют лимиты частоты запросов на вход, наставника, оплату и картинки.
